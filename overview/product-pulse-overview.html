STAEDEAN Product Pulse — programme overview

Product Pulse: how it fits together

One landing page, twelve Teams webinars and two HubSpot emails a year work as one system — this page is the map, the monthly checklist, and the RACI for Tim, marketing and IT.

Architecture

Four systems, each doing one job. HubSpot only brings people to the page; Teams owns everything after someone registers.

live flow (this round) phase 2, optional accent border = the two customer-facing surfaces (landing page, webinar)

Monthly operating loop

Repeats twelve times a season. Everything except the T-1h reminder is a manual, five-minute step.

T−30 days

Create or verify next month's webinar

Create the Teams webinar (or run the optional Graph script), then paste the registration URL into site/sessions.json and commit on GitHub — the Actions workflow auto-deploys.

Tim (or IT, script, Tim stays organizer)
T−10 days

HubSpot monthly invite sends

The "next pulse" email goes to the Product Pulse audience list, with the topic teaser and a UTM-tagged Register link to the landing page.

Marketing
T−1 hour

Teams reminder

Teams automatically emails every registrant a reminder. No manual step, nothing to configure per pulse.

Automatic (Teams)
T+0

The pulse runs

30 minutes, live Q&A, recorded. Tim presents; a co-organizer can watch the chat.

Tim
T+1 day

Publish the recording

Download the MP4 from Tim's OneDrive, upload it to YouTube unlisted, paste the video URL into sessions.json and commit on GitHub so it appears under "Past pulses".

Decisions & open items

What Henry already decided, and what still needs an answer before the season can be fully scheduled.

Decided

  • Recordings are published to YouTube, unlisted.
  • Hosting is GitHub Pages, served directly from the GitHub repo via a GitHub Actions workflow, with a scripted fallback (Deploy-Site.ps1) for manual commit/push or a legacy branch-based Pages deploy. Live as of 2026-09-08 at staedean-b-v.github.io/SDN-PULSE/.
  • 2026-09-08: keep the current staedean-b-v.github.io/SDN-PULSE/ URL for now; switch to pulse.staedean.com later (DNS at EuroDNS, Henry has access).
  • This round's deliverable is a working landing page, the supporting docs and this HTML overview — not the live deployment.
  • HubSpot's role is discovery only: season kickoff plus one monthly invite. Teams owns every registrant communication after that (confirmation, calendar invite, reminder, cancellation).

Open (not blocking the build)

  • Custom domain switch to pulse.staedean.com is pending - DNS is at EuroDNS (Henry has access); CNAME record and repo Settings > Pages change still to be done.
  • Fixed monthly slot and the remaining 2026 dates, from Tim.
  • IT tenant check: anonymous join enabled, Teams Enterprise webinar features present.
  • HubSpot admin to install the Teams Webinars integration and create the "Product Pulse" subscription type.
  • YouTube channel: existing STAEDEAN channel or a new one, and who uploads.
Reminder for the pitch: Graph's webinar API is delegated-only for creating webinars as another organizer — there is no pure app-only path. Either Tim creates the 12 webinars himself, or IT runs the script signed in as Tim (delegated), or IT registers an app with an application access policy scoped to Tim's account. Being Global Admin does not make Tim the organizer.
